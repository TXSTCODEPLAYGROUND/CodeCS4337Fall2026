CS4337 Fall 2026
================

Documentation for the course code. Each top-level folder in the repository is
a self-contained Python package. The HTML pages are generated by Sphinx from
the docstrings in that package.

The projects come in two series, one per network, each going from plain
PyTorch to PyTorch Lightning to Lightning with Weights & Biases tracking. The
``LitWB...`` projects are the recommended pattern for your own experiments.
The last section adds an automatic hyperparameter search with Optuna.

Building these pages
--------------------

From the repository root, with only the documentation requirements installed
(PyTorch and Lightning are not required):

.. code-block:: bash

   python -m venv .venv-docs
   source .venv-docs/bin/activate
   pip install -r docs/requirements.txt
   cd docs
   make html

Open ``docs/_build/html/index.html`` in a browser. The build output is not
committed.
