PyTorch slice the head, then choose which layers train
import torch
import torch.nn as nn
from torchvision import models
from torchvision.models import ResNet18_Weights

# 1. Load pretrained ResNet18 (normalize inputs with ImageNet mean/std)
model = models.resnet18(weights=ResNet18_Weights.DEFAULT)

# 2. Keep the head: copy only your classes' rows (label i -> idx[i])
idx = torch.tensor([0, 217, 482, 491, 497, 566, 569, 571, 574, 701])
old_fc = model.fc
model.fc = nn.Linear(old_fc.in_features, len(idx))
with torch.no_grad():
    model.fc.weight.copy_(old_fc.weight[idx])
    model.fc.bias.copy_(old_fc.bias[idx])

# 3. Partially freeze: only layer4 and fc train
for name, p in model.named_parameters():
    p.requires_grad = name.startswith(("layer4.", "fc."))

# 4. One stage, low LRs (head needs no warm-up)
optimizer = torch.optim.Adam([
    {"params": model.layer4.parameters(), "lr": 1e-5},
    {"params": model.fc.parameters(),     "lr": 1e-4},
])
fastai plain Learner + splitter, since vision_learner replaces the head
from fastai.vision.all import *
from torchvision.models import resnet18, ResNet18_Weights

# Imagenette folders are ImageNet wnids; sorted vocab matches idx order
path = untar_data(URLs.IMAGENETTE_160)
dls = ImageDataLoaders.from_folder(path, valid="val", item_tfms=Resize(160),
                                   batch_tfms=Normalize.from_stats(*imagenet_stats))

model = resnet18(weights=ResNet18_Weights.DEFAULT)
idx = [0, 217, 482, 491, 497, 566, 569, 571, 574, 701]
old_fc, model.fc = model.fc, nn.Linear(512, len(idx))
with torch.no_grad():
    model.fc.weight.copy_(old_fc.weight[idx]); model.fc.bias.copy_(old_fc.bias[idx])

# Param groups: [stem + layer1-3] [layer4] [fc]
def splitter(m):
    return [params(nn.Sequential(m.conv1, m.bn1, m.layer1, m.layer2, m.layer3)),
            params(m.layer4), params(m.fc)]

learn = Learner(dls, model, splitter=splitter,
                metrics=[accuracy, F1Score(average="macro")])
learn.freeze_to(1)   # freeze group 0; train layer4 + fc
learn.fit_one_cycle(3, lr_max=slice(1e-5, 1e-4))
Why keep the head?Its rows already map 512-d features to your classes. Starting from a good head avoids the noisy random-head gradients that distort pretrained features (the idea behind LP-FT).
Why partially freeze?Fewer trainable parameters means less overfitting and forgetting on small data. Early layers are generic; which block to tune depends on the shift (surgical fine-tuning).
Slice vs. maskSlicing gives a true 10-way softmax for training. Masking the other 990 logits gives identical predictions and is the standard way to evaluate on ImageNet-A/R subsets.
Only when classes overlapThis works only if your classes are in the source label set. For new classes (or relabeled ones), replace the head instead. Partial freezing is common; head slicing is a niche choice.
